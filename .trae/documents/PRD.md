# 产品需求文档 (PRD) - AI简历优化器 v2.0

## 1. 产品概述

### 1.1 产品定位
一款专业的AI简历优化Web应用，帮助用户提升简历质量，增强求职竞争力。

### 1.2 核心价值主张
- **HR视角诊断**：以资深HR的视角分析简历，找出关键问题
- **智能优化重写**：基于STAR法则、量化成果、专业术语优化简历
- **岗位精准匹配**：根据目标职位描述，分析简历匹配度并给出优化建议

## 2. 目标用户

| 用户类型 | 特征 | 核心需求 |
|---------|------|---------|
| 应届毕业生 | 缺乏简历撰写经验 | 需要指导如何展示实习经历和项目 |
| 职场新人(1-3年) | 有一定工作经验但不知如何表达 | 需要学会量化成果，使用专业术语 |
| 职场转型者 | 跨行业求职 | 需要突出可迁移能力，匹配新岗位要求 |
| 资深职场人士 | 经验丰富但简历冗长 | 需要精简内容，突出核心竞争力 |

## 3. 核心功能需求

### 3.1 功能一：简历诊断分析模式

#### 3.1.1 功能描述
用户上传简历后，AI以资深HR的视角分析简历，找出问题并给出具体改进建议。

#### 3.1.2 诊断维度
| 维度 | 检查项 | 输出内容 |
|------|--------|---------|
| 内容完整性 | 基本信息、工作经历、教育背景、技能特长 | 缺失项提醒 |
| 内容质量 | 是否有量化成果、是否突出个人贡献 | 具体问题点 |
| 语言表达 | 是否有模糊词汇、语法错误、专业度 | 语言改进建议 |
| 结构合理性 | 信息排序、段落结构、可读性 | 结构优化建议 |
| 关键词匹配 | 行业关键词、岗位相关术语 | 关键词补充建议 |

#### 3.1.3 输出格式
```
【诊断报告】
• 总体评分：X/100
• 主要问题列表（按严重程度排序）
  - 问题1 + 改进建议
  - 问题2 + 改进建议
  - ...
• 优化优先级建议
```

### 3.2 功能二：AI优化重写模式

#### 3.2.1 功能描述
AI根据诊断结果和优化标准，直接重写简历内容，输出专业、简洁、有吸引力的简历。

#### 3.2.2 优化标准
| 标准 | 要求 | 示例 |
|------|------|------|
| 量化成果 | 每项经历包含具体数字 | "提升效率30%"、"节省成本50万元" |
| STAR法则 | 情境-任务-行动-结果结构 | 清晰展示完整工作流 |
| 专业术语 | 融入行业关键词 | 根据岗位自动识别 |
| 简洁有力 | 动词开头，避免模糊表达 | "主导"、"负责"、"优化" |

#### 3.2.3 输出格式
```
优化后的简历内容
• 原始内容 → 优化后内容 对比展示
• 修改说明（为什么这样改）
• 可量化的改进点标注
```

### 3.3 功能三：岗位匹配分析

#### 3.3.1 功能描述
用户输入目标岗位描述（JD），AI分析简历与岗位的匹配度，并建议强化相关经历。

#### 3.3.2 分析维度
| 维度 | 分析内容 |
|------|---------|
| 技能匹配度 | 简历技能 vs 岗位要求 |
| 经验匹配度 | 工作经历 vs 岗位要求 |
| 关键词覆盖率 | 简历中是否包含JD关键词 |
| 能力缺口 | 缺少的关键能力或经验 |

#### 3.3.3 输出格式
```
【岗位匹配报告】
• 匹配度评分：X%
• 技能匹配情况
  - ✅ 匹配的技能/经验
  - ⚠️ 需要强化的技能/经验
  - ❌ 缺少的关键能力
• 优化建议
  - 建议在简历中强化XXX经历
  - 建议补充XXX关键词
  - 建议突出XXX能力
```

### 3.4 功能四：多模式切换

#### 3.4.1 模式选项
| 模式 | 功能 | 适用场景 |
|------|------|---------|
| 诊断模式 | 找出问题 + 改进建议 | 想了解简历问题，自己修改 |
| 优化模式 | 直接优化重写 | 快速获得优化后的简历 |
| 诊断+优化 | 先诊断后优化 | 全面了解并获取优化结果 |
| 岗位匹配 | 分析岗位匹配度 | 针对特定岗位优化简历 |

## 4. 用户体验需求

### 4.1 操作流程
```
1. 上传简历（PDF/Word）
2. 选择优化模式
3. 输入目标岗位（可选）
4. AI分析处理
5. 查看结果（诊断报告/优化内容/匹配报告）
6. 导出优化后的简历
```

### 4.2 界面需求
- 清晰的操作步骤指示
- 实时显示处理进度
- 对比视图（原文 vs 优化后）
- 一键复制和导出功能

## 5. 技术需求

### 5.1 前端技术
- **框架**：Next.js 14+ (App Router)
- **语言**：TypeScript
- **样式**：Tailwind CSS
- **UI组件**：自定义组件库
- **图标**：Lucide React

### 5.2 后端技术
- **API路由**：Next.js API Routes
- **文件解析**：pdf-parse、mammoth
- **AI服务**：支持多厂商（OpenAI、Claude、Qwen、硅基流动）

### 5.3 性能需求
- 文件上传：< 5秒
- AI响应：< 30秒
- 页面加载：< 2秒

## 6. 非功能需求

### 6.1 安全性
- API Key本地存储，不上传服务器
- 文件处理完成后自动清理
- 支持HTTPS

### 6.2 可用性
- 响应式设计（桌面优先）
- 清晰的操作指引
- 错误处理和重试机制

### 6.3 可扩展性
- 支持添加新的AI厂商
- 支持添加新的简历模板
- 支持多语言（未来扩展）
